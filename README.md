# KodaStudio

Sitio web estático para KodaStudio, una empresa en crecimiento.

## Desarrollo local

Sirve la carpeta raíz con un servidor HTTP local para que el navegador pueda cargar los módulos JavaScript:

```sh
python -m http.server 8000
```

Después, abre `http://localhost:8000`.

Consulta [docs/arquitectura.md](docs/arquitectura.md) para conocer la organización del proyecto y sus decisiones técnicas.
